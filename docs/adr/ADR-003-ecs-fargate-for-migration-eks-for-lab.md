# ADR-003 ECS Fargate for the migration replatform; EKS for this lab
Status: Accepted. Migration Phase 10 uses ECS Fargate for a like-for-like comparison with Azure Container Apps; this EKS lab is a separate standalone project reusing the same application. Rationale: no EKS control-plane fee in the comparison; lower effort; EKS lab demonstrates Kubernetes Day-2 skills.
