# Consolidated v3 starter — no separate overlay required

This package is a merged local **starter repository**, built from `eks-lab-repo-pack-v2(1).zip` and `EKS-v3-safety-patch-and-start-guide.zip`. It retains all 43 original scenario IDs/waves, the v2 architecture and app specification, and the targeted v3 safety controls. `START-HERE.md` supersedes the overlay's original installation instructions. The original v3 sources included recreated (rather than recovered byte-for-byte) safety files; the owner should review the contract before accepting it for live writes.

No AWS/GitHub/Kubernetes writes or full deployments were performed while consolidating. Lifecycle scripts remain blocked. See `docs/CONSOLIDATION-NOTES.md` for file merge details and test results.
